# AI disclosure

This package is developed by AI agents under human direction. Humans define the intended
behavior and review the acceptance tests.

The source code and unit tests are written entirely by agents and have not been reviewed
by humans.

Agents also commit code, create pull requests, create releases and perform other
repository tasks when instructed by humans.

This is the future of software development, and humans should to embrace it.
Working this way lets humans focus on understanding problems, defining intent, judging resuls and
solving needs.
