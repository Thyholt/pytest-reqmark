# AI disclosure

Humans and AI agents decide intended behavior together. Agents write acceptance tests first.
Humans read and approve them before implementation.

Agents require runnable examples of hard testing or specification problems to justify substantial
changes, including cases that must not pass. They choose architecture and implementation details,
write the code and unit tests, and demonstrate the results. Humans judge whether these solve the
problem. Passing tests alone do not establish that the expected behavior is correct.

The source code and unit tests are written entirely by agents and have not been reviewed by humans.
Agents also commit, open pull requests and create releases when instructed by humans.

This was written by AI.
