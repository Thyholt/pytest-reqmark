# AI disclosure

This package is developed by AI agents in collaboration with humans. Humans read acceptance
tests and work with agents to decide intended behavior. Agents write acceptance tests first.
Humans review and approve those tests before implementation and judge whether the demonstrated
results solve the problem.

Agents require proof that a substantial behavior change is needed: a concrete, runnable example
of a hard testing or specification problem, with expected outcomes and a negative case that must
not be reported as success. Agents investigate solutions, decide implementation details and
architecture, and demonstrate the results. A passing agent-written suite alone is not proof
that the example is realistic or that its expected outcomes are correct.

The source code and unit tests are written entirely by agents and have not been reviewed
by humans.

Agents also commit code, create pull requests, create releases and perform other
repository tasks when instructed by humans.

This is the future of software development, and humans should to embrace it.
Working this way lets humans focus on understanding problems, defining intent, judging results and
solving needs.
